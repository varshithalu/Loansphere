
# 💰 LoanSphere – AI Powered Loan Management Platform

## 📌 Overview

LoanSphere is a full-stack loan management platform built to streamline loan application, approval, risk analysis, and borrower management. The system supports multiple user roles including Borrowers, Lenders, and Admins.

The platform integrates AI-powered risk assessment using Machine Learning models such as XGBoost to evaluate loan approval probability and borrower credibility.

---

## 🚀 Features

* Multi-role authentication system
* Borrower loan application portal
* Lender review dashboard
* Admin management panel
* AI-based loan risk assessment
* XGBoost model integration
* Secure login and role access control
* Loan tracking and approval workflow
* Responsive UI dashboards

## 🧠 AI Risk Assessment Workflow

1. Borrower submits loan application
2. Financial details are validated
3. Data preprocessing is performed
4. XGBoost model evaluates risk probability
5. Risk score generated
6. Lender receives AI-assisted recommendation
7. Loan approval or rejection decision made
